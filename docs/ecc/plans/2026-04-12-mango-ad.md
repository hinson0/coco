# 接入芒果聚合广告，替换 AdMob

**日期：** 2026-04-12
**分支：** feat/mango-ad
**状态：** Phase 0 等待中（芒果平台审核）

## 背景

项目使用 Google AdMob 作为广告 SDK，但 AdMob 在国内填充率极低，用户经常看到"暂无广告"。调研后选定芒果聚合广告平台（mangolm.com），支持个人开发者、无需企业资质/软著/应用商店上架，聚合穿山甲+优量汇+快手等头部广告源。

## 需求

1. 移除 AdMob，接入芒果聚合广告作为唯一广告源（不做兜底）
2. 广告形式不变：开屏广告 + 激励视频
3. 权益系统不变（entitlements 逻辑完全保留）

### Phase 1：创建 expo-mango-ad Native Module ✅

复用 expo-pangle 架构骨架，创建新模块：

```
modules/expo-mango-ad/
├── src/ExpoMangoAd.ts           # JS API 层
├── src/ExpoMangoAd.types.ts     # TypeScript 类型
├── ios/ExpoMangoAdModule.swift   # iOS 实现（当前 mock）
├── ios/ExpoMangoAd.podspec
├── android/.../ExpoMangoAdModule.kt  # Android 实现（当前 mock）
├── android/build.gradle.kts
├── plugin/withMangoAd.ts         # Expo Config Plugin
└── expo-module.config.json
```

**JS API：**
- `init(config: { appId: string }): Promise<void>`
- `showSplashAd(slotId: string): Promise<SplashAdResult>`
- `loadRewardedVideo(slotId: string): Promise<void>`
- `showRewardedVideo(): Promise<RewardedVideoResult>`
- `onAdLoaded / onAdClosed / onAdError` 事件监听

### Phase 2：替换开屏广告 ✅

- `app/_layout.tsx`：AdMob `AppOpenAd` → 芒果 `showSplashAd`
- SDK 初始化在首次开屏广告时触发（`mangoInitRef` 防重复）

### Phase 3：替换激励视频 ✅

- `app/(tabs)/bills.tsx`：AdMob `RewardedAd` → 芒果事件驱动模式
