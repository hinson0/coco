可交互

鼠标/触摸按住「按住说话」→ 录音，向上拖动 → 取消
松开发送或取消，体验完整三态流转

设计说明

交互流程

idle 轻触切换文字/语音模式
grant 按住 → 触发录音，底部浮层上滑出现
move 手指上移 > 50pt → 进入取消态
cancel 松手 → 丢弃录音
release 正常松手 → 发送语音

视觉反馈层次

第1层：按钮本身 — 背景色 / 描边 / 外发光随状态变化
第2层：底部浮层 — 声纹波形条跟随音量实时跳动
第3层：取消指示 — 上方浮现 ✕ 图标 + "上滑取消" 文字
第4层：计时器 — 红点闪烁 + 录音时长

配色映射

sage 绿 = 录音中，安全状态
coral 红 = 取消态，危险/中止
cream 原色 = 空闲态，中性

与现有实现的改进

1. 新增取消指示器（✕ 图标浮层），给用户明确的上滑目标
2. 新增录音计时器（红点 + 时间），比在按钮上显示更清晰
3. 按钮增加外发光(glow)效果，三态区分度更强
4. 取消态 ✕ 图标放大高亮，确认即将取消的意图
