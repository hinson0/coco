## code-review

Code review a pull request

它来自 code-review 插件（claude-plugins-official 官方插件市场），不是 Superpowers 插件。文件路径是：

~/.claude/plugins/cache/claude-plugins-official/code-review/unknown/commands/code-review.md

这是一个专门用于对 GitHub Pull Request 进行代码审查的技能，需要通过 gh CLI 工具与 GitHub 交互。所以它要求有一个已存在的 PR
才能工作。
