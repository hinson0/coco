| 层级 | 功能 | 条件 |

## 3. 意见反馈页面

**文件**: `apps/mobile/app/feedback.tsx`

### 3.1 页面结构

```
┌─────────────────────────────┐
│  ← 意见反馈         Header  │
├─────────────────────────────┤
│                             │
│  反馈类型                    │
│  [功能建议] [Bug报告] [其他] │  标签选择，单选
│                             │
│  问题描述                    │
│  ┌─────────────────────────┐│
│  │ 请描述你的问题或建议...   ││  TextInput, multiline
│  │                         ││  最少 10 字
│  │                         ││  最多 500 字
│  │                         ││
│  └─────────────────────────┘│
│  右下角显示字数 xx/500       │
│                             │
│  联系方式（选填）            │
│  ┌─────────────────────────┐│
│  │ 邮箱或微信号             ││  单行 TextInput
│  └─────────────────────────┘│
│                             │
│  ┌─────────────────────────┐│
│  │       提交反馈            ││  底部按钮，跟随键盘
│  └─────────────────────────┘│
└─────────────────────────────┘
```

### 3.2 交互说明

- 反馈类型默认选中"功能建议"
- 描述字数不足 10 字时，提交按钮置灰
- 提交时拼接为 mailto URL：`mailto:feedback@example.com?subject=【{类型}】棉花记反馈&body={描述}\n\n联系方式：{联系方式}`
- 调用 `Linking.openURL(mailtoUrl)` 打开邮件客户端
- 若用户未安装邮件客户端，弹 Alert 提示"请发送邮件至 feedback@example.com"
- 按钮位置跟随键盘高度（`Keyboard.addListener`）

## 6. 通用约定

- 所有新页面遵循项目现有模式：`useSafeAreaInsets()` + 标准 Header（← 返回 | 标题 | 占位）
- 配色使用 `constants/theme.ts` 中的 colors/shadows/radii
- 按钮跟随键盘高度（反馈页）
- 纯 UI 展示，不涉及后端 API 调用
- 导航使用 expo-router 的 `router.push()` / `router.back()`
