🔄 核心数据流（以 OCR 记账为例）

① 用户拍照
→
② BFF 接收图片
→
③ 腾讯云 OCR 识别
→
④ GLM 提取金额/类别
→
⑤ 返回预填表单
→
⑥ 用户确认保存

设计原则：AI 识别结果始终先展示给用户确认，再写入数据库。避免自动写入错误数据。
