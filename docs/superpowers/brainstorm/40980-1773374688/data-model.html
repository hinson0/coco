数据模型设计

Section 2 / 4 — Supabase PostgreSQL 核心表结构

👤 users (Supabase Auth 自动创建)
-- 由 Supabase Auth 管理
id uuid PRIMARY KEY
email text
created_at timestamptz
🏷️ categories (消费分类)
id uuid PRIMARY KEY
user_id uuid → users.id
name text -- 餐饮/交通...
icon text -- emoji
type enum(income, expense)
is_default boolean
💰 transactions (账单记录 — 核心表)
id uuid PRIMARY KEY
user_id uuid → users.id
category_id uuid → categories.id
amount numeric(12,2)
type enum(income, expense)
note text
occurred_at timestamptz -- 消费时间
source enum(manual, ocr, asr)
raw_input text -- 原始语音/OCR文本
receipt_url text -- Supabase Storage
ai_confidence float -- AI 识别置信度
created_at timestamptz
🎯 budgets (预算)
id uuid PRIMARY KEY
user_id uuid → users.id
category_id uuid -- null=总预算
amount numeric(12,2)
period enum(monthly, yearly)
start_date date
🔍 nl_query_logs (NL 查询日志)
id uuid PRIMARY KEY
user_id uuid → users.id
question text
generated_sql text
result_summary text
created_at timestamptz
📌 设计说明：
  • source 字段记录每笔账单的录入方式，便于后续分析 AI 功能使用率
  • raw_input 保留原始语音文字 / OCR 文本，供用户对照核查
  • ai_confidence 低于阈值（如 0.7）时前端展示警告提示用户核对
  • RLS (Row Level Security) 全表启用，用户只能查询自己的数据
