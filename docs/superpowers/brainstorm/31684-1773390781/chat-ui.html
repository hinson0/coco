🎯 核心理念

一个聊天窗口 = 所有记账入口。用户无需理解"手动/OCR/ASR"的区别，想怎么记就怎么记。

📥 输入方式融合

🎙️ 语音：长按右侧麦克风按钮，松手发送 → ASR → GLM → 账单卡片
📷 拍照：点击左侧相机按钮，拍照发送 → OCR → GLM → 账单卡片
⌨️ 文字：直接打字"午饭 35" → GLM 解析 → 账单卡片
💬 查询：输入"这周花了多少" → NL Query → 文字 + 图表答复

🃏 账单卡片

  • AI 自动生成，直接写入 DB
  • 卡片内嵌 编辑 / 删除 操作
  • 低置信度时卡片加 ⚠️ 标记
  • 支出红色左边框，收入绿色左边框

✏️ 手动记账

点击快捷栏 "手动记账" → 弹出传统表单
（金额键盘 + 分类选择 + 备注 + 日期）
💡 聊天历史 = 记账流水
聊天记录本身就是一份带时间线的消费日志，用户翻聊天就能回顾最近的开销。
