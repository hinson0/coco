✏️ 记账页交互流程

手动输入
金额键盘 → 选分类 → 填备注(可选) → 选日期(默认今天) → 保存
📷 拍照识票
点击拍照 → loading → Toast "已记录 餐饮 ¥35" → 账单列表自动刷新
🎙️ 语音记账
长按录音 → 松手 → loading → Toast "已记录 交通 ¥12" → 账单列表自动刷新

💬 自然语言查询

首页顶部搜索框，输入自然语言 → BFF 处理 → 返回卡片式结果
Q: "上周吃饭花了多少钱"
A: "上周餐饮类消费共 ¥287.50，共 8 笔。最大一笔 ¥68（周六聚餐）"
